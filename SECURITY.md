# Security policy

## Supported versions

Only the latest release on the [Releases page](https://github.com/Skyflash/RoboXCopy/releases) receives fixes.

## Reporting a vulnerability

Please report security problems privately, not in a public issue:
use [private vulnerability reporting](https://github.com/Skyflash/RoboXCopy/security/advisories/new)
(the "Report a vulnerability" button in the Security tab).

Include the version, the Windows version, and the steps to reproduce. You will get an answer as soon as
possible; this is a one-person project, so allow a few days.

## Verifying a download

Releases are not code-signed. Each release carries a SHA-256 checksum and a GitHub build attestation;
see [Security and verification](https://roboxcopy.com/signing.html) for how to check them.
